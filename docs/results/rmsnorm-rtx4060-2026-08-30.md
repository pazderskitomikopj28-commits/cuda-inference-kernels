# RMSNorm results — RTX 4060 Laptop GPU

Benchmark source commit: `d4a83c8a97d2651a0412344c8e57a59a9533e952`.
The Systems-only profiling fallback was added in
`89e1ba5cf3b4d2ef17425119c1cc254e1a666cd8`.

## Environment and protocol

- GPU: NVIDIA GeForce RTX 4060 Laptop GPU, compute capability 8.9;
- driver 591.74; CUDA 12.4.131; MSVC 19.38.33145; Release `sm_89` build;
- input and output: 4096 rows × 4096 hidden elements, FP32;
- weight: 4096 FP32 elements; epsilon: `1e-5`;
- block size: 128 threads, selected by the sweep below;
- every process ran 10 warm-up and 100 measured invocations;
- each invocation was timed by CUDA Events; five fresh processes were run for
  every variant, with execution order alternated;
- process-level Mean/P50/P95 below are calculated from each process's internal
  P50; P95 uses nearest rank.

Each run evenly checked 8192 output elements against a double-precision Host
reference. Unit tests separately checked every output for small tensors,
including a hidden size of 1003 on the scalar path.

```powershell
rmsnorm_bench.exe --mode all --rows 4096 --hidden 4096 `
  --block-size 128 --warmup 10 --iters 100
```

## Variant comparison

| Variant | Process P50 ms (mean/P50/P95) | Logical GB/s at P50 | Speedup vs two-pass | Maximum error |
| --- | ---: | ---: | ---: | ---: |
| Two-pass | 1.033216 / 1.033216 / 1.033216 | 194.854 | 1.0000× | 3.605e-7 |
| Fused scalar | 0.657405 / 0.657408 / 0.657408 | 306.243 | 1.5717× | 3.605e-7 |
| Fused `float4` | 0.611277 / 0.611328 / 0.612224 | 329.327 | 1.6901× | 3.466e-7 |

Fusion removes one Kernel launch and the global row-scale handoff while keeping
the same two source-level input passes. Vectorization adds another 1.0754× over
the fused scalar implementation. `logical_GBps` counts one input, one logical
weight and one output access per element; the small weight vector is cacheable,
so this number is not claimed to be physical DRAM bandwidth.

## Block-size sweep

The fused `float4` path was measured in five fresh processes for each block
size, with the same 10 warm-up and 100 measured invocations:

| Threads per block | Process P50 ms (mean/P50/P95) |
| ---: | ---: |
| 64 | 0.618678 / 0.618496 / 0.619520 |
| 128 | 0.611533 / 0.611328 / 0.612352 |
| 256 | 0.619213 / 0.619520 / 0.620032 |
| 512 | 0.626048 / 0.626128 / 0.626640 |
| 1024 | 0.809254 / 0.808960 / 0.810496 |

The 128-thread choice is only 1.17% faster than 64 threads at P50, but it is
repeatable across the five runs. The 1024-thread result is clearly worse. This
selection is specific to this shape and GPU and remains a runtime option.

## Nsight Systems and SASS evidence

Systems profiles contain one warm-up and five measured invocations. The
two-pass report contains 12 Kernel instances; the fused report contains six:

| Kernel | Instances | Median duration |
| --- | ---: | ---: |
| `row_inverse_rms_kernel` | 6 | 379.978 µs |
| `apply_rmsnorm_kernel` | 6 | 727.189 µs |
| `fused_rmsnorm_float4_kernel` | 6 | 602.903 µs |

Profiler instrumentation changes absolute time, but the launch count and the
two-to-one versus one-to-one structure verify the fusion mechanism. The fused
profile's duration also remains close to the unprofiled Event result.

`cuobjdump --dump-sass` shows three `LDG.E.128` instructions and one
`STG.E.128` instruction in the vectorized Kernel, confirming that the compiler
preserved 128-bit input/weight loads and output stores. Resource usage is 22
registers per thread and 132 bytes of static shared memory per block, compared
with 18 registers per thread and the same shared memory for the fused scalar
Kernel.

Nsight Compute 2026.2.1 and the retained driver-matched 2025.4.1 build both fail
to initialize on this Windows host with exit code `-1073740791`, even for
`--query-metrics`. The attempted CSV files are empty, so this report does not

## Correctness and safety

CTest passed `1/1`. Compute Sanitizer reported zero memcheck errors and zero
racecheck hazards. The vectorized API rejects hidden sizes that are not divisible
by four instead of silently issuing misaligned row accesses.
